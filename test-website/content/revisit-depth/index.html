Revisit at different path depth

Reproduces openzim/warc2zim#471: several documentation-style pages (mimicking docs.python.org's "Improve this page" links) all point to the exact same improve-page.html, each with a different query string containing another URL (with un-encoded slashes), just like the real docs.python.org pages do. Since the server ignores the query string, every request to improve-page.html returns byte-identical content, so a crawler with content de-duplication enabled (e.g. Browsertrix Crawler) will capture it once as a real response and record the rest as WARC revisit records.

improve-page.html loads a relative stylesheet (../style.css). Open each link below and check the resulting page: if the box is green, the relative link resolved correctly for that particular copy of the page; if it is unstyled, the link broke.
