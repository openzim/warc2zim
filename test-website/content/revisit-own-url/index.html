Revisit served at its own URL

Reproduces openzim/warc2zim#507: route-a.html and nested/route-b.html are byte-for-byte identical files at two different path depths, like a single-page application reusing its static shell markup across different routes. The shell reads its own window.location.pathname to decide what to display, and links back to this page using an absolute path (/revisit-own-url/index.html), just like a real site would, rather than one already written relative to its own depth.

A crawler with content de-duplication enabled (e.g. Browsertrix Crawler) will capture one of these pages as a real response and record the other as a WARC revisit. Open each link below and check two things: the displayed path should match the URL you're actually on (not the other page's), and the "Back to this demo" link should work correctly from both, despite being written identically in both files.
